# Framefolio · 银幕手记

一个极简黑白风格的个人电影档案。公开页面用于浏览电影、筛选评分和阅读影评；管理后台用于搜索 TMDB、创建草稿、填写影评并发布。

## 第一次使用

1. 在 TMDB 注册账号并申请 API Read Access Token。
2. 将 `.env.example` 复制为 `.env.local`，填写 `TMDB_READ_TOKEN`。本地预览会使用内置的测试管理员身份，因此 `OWNER_EMAIL` 可以暂时留空。
3. 安装依赖并执行 `npm run build`。
4. 按 `drizzle/` 中的顺序将尚未执行的迁移应用到本地 D1 数据库。
5. 执行 `npm run dev`，访问终端显示的本地地址。
6. 点击“管理”，使用本地测试身份登录，然后搜索并记录第一部电影。

当前工作区已经完成依赖安装、首次构建和首次本地数据库迁移，可以直接继续使用已运行的预览。

Windows 可双击 `start-framefolio.cmd` 启动本地网站，需要先安装 Node.js。

## 数据归档

电影资料与个人影评快照统一放在 `data/archive/`，包含草稿。运行 `npm run data:export` 更新该目录后再提交到 GitHub。该仓库公开，归档内容也公开；真实 TMDB 密钥只放在被 Git 忽略的 `.env.local` 或部署平台的服务端密钥配置中。

托管平台要求使用 `.openai/hosting.json` 作为部署清单，因此保留该固定路径。身份验证的协议路径以及第三方代码的版权声明同样保留；它们不代表网站品牌。

## 正式发布前

- 将 `OWNER_EMAIL` 设置为唯一管理员的 ChatGPT 登录邮箱。
- 将 `TMDB_READ_TOKEN` 作为服务端密钥配置，不能写入公开代码。
- 将本地确认过的电影记录迁移到线上 D1 数据库，并核对数量与影评内容。
- 保留 `/about` 页面中的 TMDB 标识和来源声明。

## 内容规则

- 草稿可以不填写评分或影评。
- 发布时评分必须是 1–10，最多保留一位小数，并且短评和长评至少填写一项。
- 标记为剧透的长评会在公开详情页默认折叠。
- 电影基本信息会在添加时保存到本站数据库，公开浏览不依赖 TMDB 实时在线。
